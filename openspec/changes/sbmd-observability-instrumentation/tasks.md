## 10. Post-review refactor: instance-based metrics classes

During PR review, it was noted that the static-only metrics class pattern (Decision 1) should not be continued with new code. All four metrics classes have been refactored to be fully instance-based.

- [x] 10.0 `MQuickJsRuntime` converted from static-only to Meyer's singleton (`static MQuickJsRuntime &GetInstance()`). All existing public static methods preserved as static wrappers calling `GetInstance()`. Private static members become non-static instance members.
- [x] 10.1 `MQuickJsRuntimeMetrics` made instance-based (no static methods or static handles). Owned as a non-static `MQuickJsRuntimeMetrics metrics` member of the `MQuickJsRuntime` singleton. `GCCallback` remains `static` (required for C callback compatibility); registered with `&rt.metrics` as the opaque parameter so the callback can reach the instance.
- [x] 10.2 `SbmdHandlerInvokerMetrics` made instance-based. Owned as a `static SbmdHandlerInvokerMetrics metrics` member of `SbmdHandlerInvoker` (class-wide). `static void InitializeMetrics()` and `static void ShutdownMetrics()` wrappers added to `SbmdHandlerInvoker`. Called by `SbmdFactory::RegisterDrivers()` and `SbmdFactory::Reset()`.
- [x] 10.3 `SbmdFactoryMetrics` made instance-based. Owned as a non-static `SbmdFactoryMetrics metrics` member of `SbmdFactory` (already a Meyer's singleton). `metrics.InitializeMetrics()` called from `RegisterDrivers()`; `metrics.ShutdownMetrics()` called from `Reset()`.
- [x] 10.4 `SpecBasedMatterDeviceDriverMetrics` made instance-based. Owned as a `static SpecBasedMatterDeviceDriverMetrics metrics` member of `SpecBasedMatterDeviceDriver` (class-wide aggregates). `static void InitializeMetrics()` and `static void ShutdownMetrics()` wrappers added. Called by `SbmdFactory::RegisterDrivers()` and `SbmdFactory::Reset()`.
- [x] 10.5 `MetricsRegistry.h` and `MetricsRegistry.cpp` deleted. `MetricsRegistry::initializeAll()` and `MetricsRegistry::shutdownAll()` calls removed from `Matter.cpp`.
- [x] 10.6 Cross-module calls (`SbmdHandlerInvoker.cpp`, `SbmdBundleLoader.cpp`, `SbmdLoader.cpp`) updated to use new `MQuickJsRuntime` static wrapper methods: `RecordJsException`, `RecordMutexWait`, `RecordHeapSnapshot`, `TickleSampler`. `SpecBasedMatterDeviceDriver.cpp` updated to use `MQuickJsRuntime::RecordMutexWait` (replacing `MQuickJsRuntimeMetrics::RecordMutexWait`) and `metrics.RecordDeferred*` (replacing `SpecBasedMatterDeviceDriverMetrics::*`).
- [x] 10.7 Unit tests updated: removed `MetricsRegistry` include/calls; replaced `MetricsRegistry::initializeAll()` with `SbmdHandlerInvoker::InitializeMetrics()` (runtime metrics initialized automatically via `MQuickJsRuntime::Initialize()`); replaced `MQuickJsRuntimeMetrics::ForceSnapshot()` and `MQuickJsRuntimeMetrics::RecordMutexWait()` with `MQuickJsRuntime::ForceSnapshot()` and `MQuickJsRuntime::RecordMutexWait()`.
- [x] 10.8 All 4 metrics classes' entire method and data-member sections moved to default-private; `friend class [OwnerClass]` added as the sole access grant; client-dictating comments removed from class doc blocks. Makes unauthorized access a compile error rather than a convention.
- [x] 10.9 `GCCallback` opaque parameter renamed from `m` to `metrics` for clarity.
- [x] 10.10 Replace explicit `InitializeMetrics()` / `ShutdownMetrics()` lifecycle with a private lazy `InitInstruments()` helper in each metrics class: called at the top of every recording method; idempotent — creates all instruments on the first call and is a no-op thereafter. Remove `SbmdHandlerInvoker::InitializeMetrics()`/`ShutdownMetrics()` static wrappers and `SpecBasedMatterDeviceDriver::InitializeMetrics()`/`ShutdownMetrics()` static wrappers. Remove all lifecycle calls from `SbmdFactory::RegisterDrivers()`, `SbmdFactory::Reset()`, `MQuickJsRuntime::Initialize()`, and `MQuickJsRuntime::Shutdown()`. Unit test setup no longer needs manual initialization calls.
- [x] 10.11 Guard all measurement code in `SbmdHandlerInvoker::InvokeHandler` with `#ifdef BARTON_CONFIG_SBMD_METRICS`: pre-call `JS_GetMemoryUsage` and `steady_clock::now()`, post-call `JS_GetMemoryUsage`, timing math, `WasInterrupted()`, `JS_GetGCRootCount()`, and all `metrics.Record*` / `MQuickJsRuntime::RecordHeapSnapshot` / `MQuickJsRuntime::TickleSampler` calls. Matches the existing pattern applied to `AcquireJsMutex()` (task 1.0). With metrics disabled the function is truly zero-overhead and does not hard-depend on the patched `JS_GetGCRootCount` symbol.

## 11. Post-review refactor: access control, initialization, and MQuickJsRuntime structure

During a subsequent PR review, `friend class` access control was replaced with standard public/private visibility, `InitInstruments()` lazy helpers were replaced with constructors, and `MQuickJsRuntime` was converted from a Meyer's singleton back to a pure static class.
